# Beyond the Numbers

**Follow your curiosity. Discover the connections.**

Beyond the Numbers is an educational math website designed to make mathematics feel like a world to explore. Through imaginative environments and approachable questions, the project invites learners to discover patterns, investigate shapes, and explore chance.

![Beyond the Numbers math universe](static/assets/images/BeyondMathHome.png)

## Project Vision

Build an exploration-based learning experience where curiosity leads the way:

**Explore → Ask questions → Experiment → Discover connections**

Beyond the Numbers is being developed as a separate companion to **Beyond the Elements**. The long-term goal is to connect subjects through shared topics, allowing learners to follow an idea from mathematics into science and beyond.

## Explore the Worlds

### Patterns
Discover how simple rules create sequences, repetition, and growth.

Planned explorations include:
- Number sequences and their rules
- Patterns in nature
- Creating patterns with shapes, colors, and numbers
- Connections to crystal arrangements in science

### Geometry
Explore the shapes, symmetry, and dimensions that help describe our world.

Planned explorations include:
- Two-dimensional shapes and three-dimensional solids
- Angles, reflections, and rotations
- Building and combining shapes
- Connections to molecular geometry

### Probability
Investigate possible outcomes and the patterns hidden in uncertainty.

Planned explorations include:
- Chance and likelihood
- Coin flips and dice rolls
- Comparing predictions with experimental results
- Connections to radioactive decay and half-life

## Current Progress

The initial visual foundation includes:

- A homepage and three subject pages
- Shared navigation between all four pages
- Responsive page layouts
- A coordinated midnight, lavender, and mint color palette
- Custom AI-generated illustrations used as full-screen backgrounds
- Outlined text and translucent content cards for readability
- Introductory sections describing future subject connections

**The project is currently a visual prototype. Interactive math activities and links to companion projects are planned but have not yet been implemented.**

## Technologies

- **HTML5** — page structure and content
- **CSS3** — styling, responsive layouts, and backgrounds
- **JavaScript** — reserved for future interactive activities

The current site requires no framework, package installation, or build step.

## View the Project Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.

For automatic refresh while editing, use the VS Code **Live Server** extension and select **Open with Live Server** on `index.html`.

## Approach to Learning Visuals

The world illustrations provide atmosphere and encourage exploration.

Future instructional models will be built with web technologies so that quantities, shapes, and results can update accurately when learners interact with them. Text, navigation, and controls remain separate from the background artwork.
